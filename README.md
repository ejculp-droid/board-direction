# Board Direction Website

This repository contains the published static site for https://board-direction.com/.

The site files are in the `public/` directory. Once the existing Netlify project is linked to this repository, each commit to `main` will publish from that directory automatically. No build command is required.

## Migration snapshot

Initial files were recovered from the immutable Netlify production deployment `6af81b6250b6238050e00fef`, published on November 14, 2026. The currently published Netlify site has not been modified by this recovery.

## Netlify

Connect the **existing** Board Direction Netlify project to `ejculp-droid/board-direction`. Use production branch `main` and publish directory `public` (also configured by `netlify.toml`).

This is a snapshot of the deployed files, not necessarily any predeployment project sources.
